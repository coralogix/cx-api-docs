# AI Applications Service overview

Manage the catalog of AI applications discovered from spans.

## Methods

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/ai/applications/v3` | List AI applications |
| `DELETE` | `/ai/applications/v3/{id}` | Delete AI application |
| `GET` | `/ai/applications/v3/{id}` | Get AI application |
| `DELETE` | `/ai/model-pricing/v3` | Delete company model pricing |
| `GET` | `/ai/model-pricing/v3` | Get company model pricing |
| `PUT` | `/ai/model-pricing/v3` | Set company model pricing |
